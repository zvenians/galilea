## Historical Context

This repository was initialized in 2023 as an exploratory workspace for modernizing the digital presence and administrative operations of the **GMAHK Galilea Balikpapan** congregation. 

The early architectural concepts explored here have since evolved into dedicated, production-grade systems:

1. **[GMAHK Galilea Web Portal (`zvenians/gmahk-galilea`)](https://github.com/zvenians/gmahk-galilea)**
   The active production congregational web portal and liturgy companion featuring full-screen cinematic chapter navigation, PWA offline caching, and Google Sheets headless CMS integration.
   - **Live Production:** [gmahk-galilea.vercel.app](https://gmahk-galilea.vercel.app)

2. **[Majelis Galilea (`zvenians/majelis-galilea`)](https://github.com/zvenians/majelis-galilea)**
   The dedicated church governance platform handling meeting minutes, resolutions, annual budget execution (*RAPBJ*), and automated document generation across 23 relational database tabs.
   - **Live Production:** [majelis-galilea.vercel.app](https://majelis-galilea.vercel.app)

3. **[GMAHK Galilea Digital Archive (`zvenians/gmahk-galilea-digital-archive`)](https://github.com/zvenians/gmahk-galilea-digital-archive)**
   The high-performance cloud media archive preserving weekly bulletins and service records organized chronologically by Sabbath date.
   - **Live Production:** [drive-galilea.vercel.app](https://drive-galilea.vercel.app)
